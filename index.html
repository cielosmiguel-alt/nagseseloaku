How to Use Your Own Drawings:

Method 1: Sprite Sheet

  • Combine all frames into one horizontal image
  • Use background-image with your sprite sheet
  • Animate background-position with steps()

Method 2: Separate Images

  • Save each frame as frame1.png, frame2.png, etc.
  • Use multiple <img> or <div> elements
  • Animate opacity with staggered delays

For GitHub Pages:

  • Upload HTML and images to your GitHub repository
  • Enable GitHub Pages in repository settings
  • Your animation will be live on the web!
